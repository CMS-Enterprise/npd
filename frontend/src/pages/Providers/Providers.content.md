# For all providers

The National Provider Directory aims to be the authoritative source of all healthcare providers in the United States. It includes any individual or organization with a NPI. With a modern directory of both provider and payer data, health plans and providers can update and maintain information easily. This directory will create a more efficient national healthcare system by reducing data collection and reporting burden on both payers and providers.

# Leveraging what you've already shared

The Directory is built on a combination of data that you have already included in your NPI application (address, specialty, etc.) as well as data from existing payer and electronic health records (EHR) companies. A full list of the information captured on a provider profile/record is available in the release notes.

# Connecting to vital services

By consolidating provider data and addresses, the directory will enable more secure communication between providers. These connections will make it easier to coordinate care and exchange patient records. For more information about the goals of the NPD, please visit the [About page](/about).
